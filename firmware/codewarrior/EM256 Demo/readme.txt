PRISMA - DEMOEM / MCF51EM256

Projeto de bancada para CodeWarrior for Microcontrollers 6.3.2.

Funcoes validadas:
- clock FEI ajustado com trim de fabrica;
- SCI3 em PTC1/TX3, 19200 baud, 8N1;
- leitura diferencial bruta dos ADC1, ADC2 e ADC3;
- telemetria JSON por linha para um adaptador CH340.

Consulte firmware/README.md e docs/bancada-demoem.md na raiz do repositorio.
Os arquivos de startup e excecoes preservam os avisos autorais do fornecedor.
